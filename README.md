# 培训证书核验系统

零外部依赖的培训证书在线核验平台，包含：

- **学员端**：输入「证书编号 + 姓名」核验证书，查看课程名称、发证日期、有效期、培训机构与证书状态；可通过**邮箱验证码**自助申请更正联系邮箱。
- **管理后台**：多管理员共同维护证书（新增 / 编辑 / 吊销恢复 / 删除 / 检索分页）；超级管理员可管理管理员账号；完整操作审计日志。
- **邮件能力**：支持 SMTP 发信（465 隐式 TLS / 587 STARTTLS，原生实现零依赖）；未配置 SMTP 时进入控制台模式，验证码输出到服务端日志与 `data/mail.log`，便于本地联调。

## 快速开始

要求 Node.js ≥ 18（推荐 20+）。

```bash
npm start
# 或开发模式
npm run dev
```

- 学员核验页：<http://localhost:3000/>
- 管理后台：<http://localhost:3000/admin>
- **首次启动默认超级管理员**：用户名 `admin`，密码 `Admin@123456`（首次登录强制修改，请在生产环境立即更换）
- 首次启动会写入 5 张示例证书覆盖全部状态类型，学员页可直接体验（如证书编号 `PX-2026-000127`、姓名 `张伟`）；删除 `data/` 后重启即恢复初始状态

## 环境变量

见 `.env.example`，可通过环境变量传入（不依赖 dotenv）：

| 变量 | 说明 |
| --- | --- |
| `PORT` / `HOST` | 监听地址，默认 `3000` / `0.0.0.0` |
| `NODE_ENV` | `production` 时会话 Cookie 增加 `Secure` 并关闭开发验证码回显 |
| `DATA_DIR` | 数据目录（JSON 文件存储，原子写入），默认 `./data` |
| `SMTP_URL` | SMTP 连接串，如 `smtps://user:pass@host:465`；留空为控制台模式 |
| `MAIL_FROM_NAME` / `MAIL_FROM_EMAIL` | 发件人名称与地址 |

生产部署建议置于 HTTPS 反向代理（Nginx/Caddy）之后，`NODE_ENV=production`。

## 邮箱更正流程（学员自助）

1. 学员先通过「证书编号 + 姓名」核验，获得 30 分钟有效的签名会话令牌（HMAC 签名，无需登录）。
2. 填写新邮箱 → 系统发送 **6 位数字验证码**（10 分钟有效）。
3. 输入验证码确认：服务端比对 SHA-256 哈希（常量时间比较），通过后更新联系邮箱。

安全限制：

- 同一证书两次发送间隔 ≥ 60 秒（重发冷却）
- 单条验证码最多尝试 5 次，超限需重新获取
- 按 IP 限流：核验 20 次/10 分钟、发码 10 次/15 分钟、确认 15 次/15 分钟
- 更正成功向新邮箱发送通知；全流程写入审计日志

## 角色与权限

| 能力 | 超级管理员 super | 编辑 editor |
| --- | --- | --- |
| 证书新增/编辑/吊销/删除 | ✅ | ✅ |
| 修改本人密码 | ✅ | ✅ |
| 管理员账号管理、重置密码 | ✅ | ❌ |
| 查看操作日志 | ✅ | ❌ |

至少保留一个启用的超级管理员；管理员不能删除/停用自己；新管理员默认首次登录需改密。

## 证书状态规则

- **有效**：未吊销且在有效期内
- **即将到期**：距截止日 ≤ 30 天
- **已过期**：超过截止日
- **已吊销**：管理员手动吊销（可附原因，对学员展示）
- 可标记「长期有效」，不设截止日

## 安全设计

- 密码：PBKDF2-SHA256（12 万轮，每用户独立盐）
- 会话：HttpOnly + SameSite=Lax Cookie，8 小时空闲过期；写操作校验 CSRF 令牌与 Origin
- 安全响应头：CSP / X-Frame-Options / X-Content-Type-Options / Referrer-Policy
- 登录失败次数限制（按账号+IP），接口全局限流
- 核验接口要求编号与姓名同时匹配才返回信息，避免证书编号枚举
- 数据文件以 `0600` 权限原子写入；审计日志保留最近 5000 条

## 目录结构

```
server.js            HTTP 服务与全部 API
lib/security.js      密码哈希 / HMAC 令牌 / 随机数 / 邮箱工具
lib/store.js         JSON 文件持久化与数据访问
lib/mailer.js        SMTP 原生客户端 + 控制台传输 + 邮件模板
lib/rate-limit.js    内存固定窗口限流
public/
  index.html         学员核验页
  admin.html         管理后台
  css/styles.css     样式
  js/app.js          学员端脚本
  js/admin.js        管理端脚本
data/db.json         运行后生成（证书、管理员、日志；勿提交）
data/mail.log        控制台模式下的邮件记录（含验证码）
```
