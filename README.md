# 培训证书核验平台

学员凭「证书编号 + 姓名」公开核验证书；多名管理员在后台维护证书；学员可通过邮箱验证码流程自行更正联系邮箱。

## 功能

### 学员侧（`/`）
- 输入证书编号与姓名，显示：课程名称、发证日期、有效期、培训机构、证书状态（有效 / 已过期 / 已吊销，含吊销原因、90 天内到期提醒）
- 信息不匹配时返回统一提示，防止证书编号被枚举
- 「申请更正联系邮箱」：向**新邮箱**发送 6 位验证码（10 分钟有效、60 秒发送间隔、最多错 5 次），验证通过后更新邮箱；发起前必须先通过一次核验
- 无 SMTP 配置（开发模式）时，验证码写入 `data/outbox.json`、打印在服务端控制台，并由接口直接回显便于联调

### 管理后台（`/admin`）
- 账号密码登录（scrypt 加盐哈希、登录限流、会话 8 小时、登录成功重新生成会话）
- 证书管理：录入 / 编辑 / 搜索 / 吊销（需填原因）/ 恢复 / 删除；编号唯一、日期与必填项校验
- 多管理员：新增管理员、启用/停用（不能停用自己）、重置他人密码、修改本人密码
- 概览统计与审计日志（登录、证书变更、邮箱更正等全部留痕，最近 5000 条）

## 快速开始

```bash
npm install        # 仅依赖 express、express-session
npm start
# 打开 http://localhost:3000
```

预置账号（请及时修改密码）：

| 账号 | 密码 | 说明 |
| --- | --- | --- |
| admin | admin123 | 系统管理员 |

## 配置真实发信

编辑 `.env`（参考 `.env.example`）：

```
# QQ 邮箱等隐式 TLS
SMTP_URL=smtps://邮箱账号:授权码@smtp.qq.com:465
# 或 587 端口 STARTTLS
SMTP_URL=smtp://用户名:密码@smtp.example.com:587
NODE_ENV=production
SESSION_SECRET=用一段长随机字符串替换
```

生产环境（`NODE_ENV=production`）接口不再回显验证码，且会话 Cookie 仅经 HTTPS 发送。
内置极简 SMTP 客户端（AUTH PLAIN / LOGIN、隐式 TLS / STARTTLS），无需额外依赖。

## 运维命令

```bash
# 重置管理员密码（忘记密码时；不提供新密码则随机生成）
# 注意：数据在服务启动时载入内存，请先停止服务再执行，完成后重启服务
npm run reset-password -- admin 新密码
```

数据以 JSON 形式保存在 `data/db.json`（原子写入）；邮件开发副本在 `data/outbox.json`。请定期备份 `data/` 目录。
